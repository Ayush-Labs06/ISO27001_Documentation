## Agenda Item Detail

### Item 2: Status of Previous Review Actions

Review actions from [previous review date]. For each action:
- Was it completed on time?
- If not complete, what is the revised plan?
- Are any actions no longer relevant (context changed)?

### Item 3: ISMS Performance — KPIs and Metrics

Present the KPI dashboard. Highlight:
- Any metric outside target
- Trend direction (improving or declining?)
- Any metric added or removed since last review

Key metrics to cover:
- Security incident count and severity breakdown
- Vulnerability open/closed rate (by severity)
- Training completion rate
- Phishing click rate (current vs. 12-month trend)
- Access review completion rate
- Patch compliance rate
- Open nonconformities count and age

### Item 4: Internal Audit Results

- How many audits completed vs. planned?
- Total NCs raised (major/minor)
- Status of corrective actions (open/closed/overdue)
- Themes — which areas keep generating findings?
- Was auditor independence maintained?

### Item 5: Risk Assessment Status

- When was the last full risk assessment?
- Any new risks identified since last review?
- Any risks that have materialised (become incidents)?
- Risk acceptance status — are any above-threshold risks still untreated?
- Residual risk level — improving or worsening?

### Item 6: IS Incidents and Near-Misses

- Total incidents in period (by severity)
- P1/P2 incidents — brief summary of each
- P3/P4 volume trend
- Near-misses and what was learned
- Were all incidents responded to per IRP?
- GDPR breach notifications made (if any)

### Item 7: Changes to Context and Interested Parties

- New regulations or legal requirements?
- Major customer contract changes with IS implications?
- Competitor incidents that affect our threat landscape?
- Organisational changes (headcount, new products, new markets)?

### Item 8: Supplier and Third-Party Status

- Any new Tier 1/2 suppliers added?
- Any supplier security incidents affecting us?
- Assessment status: any overdue reviews?
- Any DPAs missing or expiring?

### Item 9: IS Objectives Progress

Review each objective from the IS Policy:
- What is the target?
- What is the current measurement?
- On track / at risk / missed?

### Item 10: Opportunities for Improvement

Open floor for:
- ISMS process improvements
- New controls to consider
- Technology changes that could improve security posture
- Areas where resource investment would have highest IS impact

## Pre-Meeting Preparation (ISMS Owner)

Distribute the following at least 2 weeks before the meeting:
- [ ] KPI dashboard (current quarter)
- [ ] Internal audit report (if completed since last review)
- [ ] Corrective action tracker (current)
- [ ] Risk register summary (top 10 risks)
- [ ] Incident log summary (period since last review)
- [ ] Subprocessor register (last review date highlighted)
- [ ] IS objectives tracking table
- [ ] Improvement backlog (prioritised)
- [ ] Previous review minutes + action status

---

## Post-Meeting (ISMS Owner)

- [ ] Draft minutes within 5 business days
- [ ] Send to CEO for approval
- [ ] Log all agreed actions in action tracker
- [ ] Update ISMS improvement backlog
- [ ] File approved minutes in ISMS document store
- [ ] Schedule next review
