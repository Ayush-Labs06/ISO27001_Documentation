# Management Review — Inputs Checklist
**ISO 27001:2022 — Clause 9.3.2 | Version 1.0**
**Complete this checklist 2 weeks before each management review.**

---

| Input Required (Clause 9.3.2) | Document | Prepared By | Ready | Notes |
|-------------------------------|---------|------------|-------|-------|
| **9.3.2(a)** Status of previous review actions | Previous MR minutes + action tracker | ISMS Owner | ☐ | All actions must be in one of: Complete / In Progress / Overdue |
| **9.3.2(b)** Changes in external/internal context | Context analysis — updated sections | ISMS Owner | ☐ | New regulations, market changes, org changes since last review |
| **9.3.2(b)** Changes in interested party requirements | Stakeholder register — changes highlighted | ISMS Owner | ☐ | New customer contracts; regulatory updates |
| **9.3.2(c)** IS performance — NCs and CAs | Corrective action tracker | ISMS Owner | ☐ | How many open? Overdue? Recurring? |
| **9.3.2(c)** IS performance — monitoring results (KPIs) | KPI dashboard (current quarter) | ISMS Owner | ☐ | Present all 8 KPI categories |
| **9.3.2(c)** IS performance — internal audit results | Latest audit report + NC status | Internal Auditor | ☐ | Include findings summary and trend |
| **9.3.2(c)** IS performance — fulfilment of IS objectives | IS objectives tracking table | ISMS Owner | ☐ | On track / at risk / missed per objective |
| **9.3.2(d)** Risk assessment results | Risk register (current) | ISMS Owner | ☐ | Top 10 risks; any new risks; acceptance status |
| **9.3.2(d)** Risk treatment plan status | Risk treatment plan | ISMS Owner | ☐ | Actions completed vs. planned |
| **9.3.2(e)** Opportunities for improvement | Improvement backlog (prioritised) | ISMS Owner | ☐ | New items; status of previous items |
| **Supplementary** Incident log summary | Incident log (period) | ISMS Owner | ☐ | Not mandatory per clause but always expected |
| **Supplementary** Supplier status | Subprocessor register + assessment status | ISMS Owner | ☐ | Overdue assessments; new Tier 1 suppliers |
| **Supplementary** BCP/DR status | Last DR test results | DevOps Lead | ☐ | RTO achieved; any gaps vs. target |
| **Supplementary** Awareness training status | Training completion report | ISMS Owner | ☐ | Completion %; phishing simulation results |

---

## Document Pack Distribution

Send the complete pack to all attendees at least 2 weeks before the meeting:

- [ ] Agenda (use `review_agenda_template.md`)
- [ ] Previous review minutes + open actions
- [ ] KPI dashboard report
- [ ] Internal audit summary (or full report if recent)
- [ ] Risk register executive summary (top risks only)
- [ ] Incident log summary (period since last review)
- [ ] IS objectives tracking table
- [ ] Improvement backlog

---

## Pre-Meeting Checklist (ISMS Owner)

- [ ] Calendar invite sent with dial-in/location
- [ ] All attendees confirmed (CEO attendance is mandatory)
- [ ] Document pack distributed 14+ days before meeting
- [ ] Presentation/slides prepared if using slides (optional but helps in larger teams)
- [ ] Any urgent items flagged in advance (e.g., open major NC; significant incident)
- [ ] Minutes template prepared for live note-taking
- [ ] Action tracker template open for real-time updates during meeting
